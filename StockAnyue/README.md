# StockAnyue · 竖向资产看板

入口为 `index.tsx`，整个 `StockAnyue` 文件夹一起导入 Await。仅声明 `extraLargePortrait`，适用于支持该尺寸的 iOS 27 或更高版本。

## 功能

- 资产市值、持仓成本、浮盈亏，按选定币种汇总。
- A 股、港股、美股、黄金和原油参考报价，以及 CoinLore 的加密资产美元聚合报价。预置 8 项，面板最多配置 16 项，表格按可用高度自动分页。
- panel 的「显示比特币 / Show Bitcoin」toggle 独立控制预置 BTC 项。默认开启；关闭后不显示 BTC、不计入持仓总览，也不请求 BTC。资产列表中的数量和成本配置仍保留。
- 持仓 / 行情切换。持仓页显示数量、成本、现价、行情涨跌、持仓盈亏；行情页显示报价日期、时间和时区。
- 上证指数 / 深证成指 / 创业板指的当日分时置于顶部，包含前收参考线、真实分时时间和刷新图标。午休不占用交易时间轴。
- 最多三只股票对比价格、涨跌幅和源接口市盈率，支持按涨跌幅或正市盈率排序。
- 总览、持仓、分时、对比可分别开关；支持修改背景及涨跌颜色。
- 资产看板标题、计价币种和资产总览置于底部。点击币种按钮，在组件内的币种浮层中选择；点选后自动关闭，也可点击关闭按钮或浮层外区域收起。
- 整行点击打开配置的详情链接；可填写目标 App 已支持的 URL Scheme 或 Universal Link。预置股票链接打开腾讯对应股票页面，是否进入 App 取决于目标 App 的链接支持。

## 填写资产

面板的资产列表中，每行使用下面的顺序，以 `|` 分隔。

```text
名称|行情代码|币种|数量|每单位成本|类型|乘数|详情链接
```

例如，持有 10 股苹果，平均每股成本 200 美元。

```text
苹果|usAAPL|USD|10|200|资产|1|https://gu.qq.com/usAAPL/gp
```

数量按实际股数或币数填写，不按证券交易的“手”填写。默认数量和成本均为 0，仅展示观察行情；不预设用户持仓。

| 字段 | 填写方式 |
| --- | --- |
| 行情代码 | A 股 `sh600519` / `sz000001`，港股 `hk01810`，美股 `usAAPL`；金油参考报价 `hf_GC` / `hf_CL`；CoinLore 使用 `coin_` 加资产 ID，比特币为 `coin_90` |
| 币种 | 报价及成本使用的币种，如 `CNY`、`USD`、`HKD`；CoinLore 项固定使用 `USD` |
| 类型 | `资产` 计入资产市值和浮盈亏；`期货` 只计估算浮盈亏；`观察` 不参与持仓计算 |
| 乘数 | 股票、币等一般填 `1`；期货填对应合约乘数 |
| 详情链接 | 可留空。填链接后整行可点击 |

普通资产浮盈亏为 `(现价 − 每单位成本) × 数量 × 乘数`。期货沿用该公式，数量可用负数表示空头；期货名义价值、保证金不计入资产市值，未计算手续费、资金费用和已实现盈亏。

`hf_GC`、`hf_CL` 是金油的连续参考报价，不是国内每克黄金价，也未绑定用户购买的具体到期合约。默认设为 `观察`；用连续报价计算的期货盈亏只能作估算。这里没有连接券商账户或自动读取交易记录。

预置比特币配置为 `比特币|coin_90|USD|0|0|资产|1|`。数量填写 BTC 枚数，每单位成本填写美元金额；CoinLore 给出的是 BTC/USD 聚合价，不是某个交易所的 BTC/USDT 成交价。开关只控制这条记录是否参与展示和请求，不删除该记录。

## 币种换算

看板支持 CNY、USD、HKD、EUR、GBP、JPY 计价。面板中的“默认计价币种”用于首次展示；在组件中选择的币种会保存，用于后续展示。法币使用 Frankfurter 每日参考汇率，一次获取全部可选币种，同一份配置每天获取一次；行情刷新不重复请求当日已获取的汇率。汇率日期会显示在底部。

点击底部币种按钮（如 `CNY ⌄`）选择其他币种，会根据缓存汇率重新折算资产总览和持仓盈亏。币种切换不清除行情缓存；请求间隔内不重复获取股票、分时或汇率。

BTC 以 USD 报价，通过同一份法币参考汇率折算至看板币种，无需手填 USDT 汇率。未将 USDT 当作 USD 使用。

成本按当前参考汇率折算，未记录买入时汇率，因此总览不是包含历史汇兑损益的券商账单。

## 数据与刷新

- 股票、金油参考报价：`https://qt.gtimg.cn/q=...`，股票合并请求。
- 指数分时：`https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=...`。
- 加密资产：`https://api.coinlore.net/api/ticker/?id=90`。按配置的 CoinLore 资产 ID 请求，关闭比特币开关后不请求 ID 90。服务说明见 [CoinLore API](https://www.coinlore.com/cryptocurrency-data-api)。
- 法币参考汇率：`https://api.frankfurter.dev/v1/latest?...`。

当前接入均不需要 API Key 或付费订阅。已只读验证预置品种的接口响应；未承诺第三方接口永久可用或覆盖全部市场。

币价和 24 小时涨跌率直接取自 CoinLore。该接口未提供源更新时间、24 小时涨跌额、最高价或最低价，不推算这些字段；行情页会明确显示「未提供涨跌额」和「未提供」源更新时间，底部仍显示本次获取时间。用户已确认其当前中国大陆网络能够打开这个 BTC 接口；这不代表所有大陆线路或未来时刻都可达。

腾讯这两个接口未查到可用的 BTC 现货报价；Frankfurter v2 虽支持 BTC，但属于工作日参考价，不用它代替盘中币价。当前代码不再请求 Binance 或 KuCoin。

自动请求间隔可选 1、5、15、30 分钟，默认 5 分钟。实际后台刷新由 iOS 调度，不能保证按设定间隔发生。指数右侧的刷新图标触发整份行情重新获取；关闭分时模块后，刷新图标显示在底部资产看板标题旁。翻页、切换模式、打开币种浮层及选择币种在请求间隔内使用同一份缓存。

“获取时间”是请求时间。行情页显示各报价自身的时间。股票涨跌按源接口的前收口径，BTC 按滚动 24 小时，金油按源参考口径；各市场时段不同，不将这些数值混称为当日持仓收益。
